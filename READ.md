# 📊 Student Productivity Analyzer

A Streamlit-based dashboard that helps analyze student expenses, study habits, sleep patterns, and overall productivity.

## 🚀 Features

* Track total expenses
* Calculate average study hours
* Identify highest expense category
* Generate a productivity score
* Visualize study trends with charts
* Analyze expense distribution using bar and pie charts
* Download student data as CSV

## 🛠️ Technologies Used

* Python
* Pandas
* Streamlit
* Matplotlib
